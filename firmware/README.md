# firmware/

Pioneer's official firmware is not in this repository. A build needs one file, the official XDJ-700 firmware version 1.15 UPD file, saved as:

    firmware/original/XDJ700.UPD
    SHA-256 73edec9802da51672257c2599efc04209dc92478fcbaa1a0425b3b122e33f99c

Everything built from it is Pioneer's firmware with our changes in it and stays out of git (`.gitignore`).
