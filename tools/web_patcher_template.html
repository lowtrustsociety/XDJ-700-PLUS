the mod is meant to complement the stock player, not to change it: what the player already plays still goes through Pioneer's own code, untouched.

everything happens locally. this page cannot load or send anything: your firmware file never leaves your computer.

it contains no Pioneer code, only the mod's own code and the places where it goes.

it refuses any file that is not the official XDJ-700 firmware version 1.15 UPD file.

      what's next
      1. open the zip. extract once it is saved. if your computer says the zip is damaged, save it again [>]
      2. copy the mod to the stick. copy 1_mod/XDJ700.UPD to the top folder of a FAT32 USB stick with about 18 MB free. keep the 2_stock_restore folder on your computer: it holds the restore file, which puts the official firmware 1.15 back.
      3. eject the stick properly, then plug it back in. this matters for the next step: without it the computer may answer from its own memory instead of reading the stick.
      4. check the file on the stick. drag XDJ700.UPD from the stick onto this box.

      5. flash. with the player switched off, put the stick in. hold IN and RELOOP/EXIT, switch the player on, and keep holding until the update screen appears. wait until the update has finished and the player has restarted. DO NOT SWITCH IT OFF before that.
      6. going back to stock. the same steps with 2_stock_restore/XDJ700.UPD. the check in step 4 recognises that file too. both files have the same name, so keep one at a time on the stick. the update screen shows for the mod and for the restore file: those numbers are only there so that the player accepts the file.
